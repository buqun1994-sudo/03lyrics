# 设计规则

1. 触发条件：调整顶栏歌词。动作：使用固定 `1920 x 1080` 设计空间和已验证安全边界，动态内容不得推动原厂控件。验证：五类图标组合、长歌词和一/两行截图。边界：未知图标不猜测占位。
2. 触发条件：调整桌面歌词。动作：歌词区域限定在架构总纲的桌面矩形内，设置页打开时临时回到顶栏策略。验证：壁纸、地图、设置页切换 smoke。边界：不覆盖状态栏和安全界面。
3. 触发条件：新增用户可见状态。动作：用用户能理解的任务、结果和下一步表达，补齐空态、加载态、失败态与权限态。验证：目标车机真实分辨率截图。边界：不在界面解释内部实现或调试参数。
4. 触发条件：新增动画或视觉效果。动作：优先低成本、不引起布局跳动的实现。验证：车机运行时观察帧率和交互。边界：禁用实时模糊、持续截图和高频装饰动画。
