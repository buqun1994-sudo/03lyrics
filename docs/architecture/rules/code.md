# 代码规则

1. 触发条件：修改播放、窗口、表面或生命周期状态。动作：沿 `LyricsOverlayService` 单一协调主链施工，不在 Activity、Receiver 或 WebView 复制状态机。验证：相关单测、构建和实机状态切换。边界：纯 UI 样式可留在对应呈现层。
2. 触发条件：新增或修改歌词源、搜索词或候选规则。动作：外部协议留在 `DirectLyricsRepository`，搜索词生成与候选选择留在 `LyricsCandidateSelector`；标题、歌手、专辑统一输出完全一致、近似、未知、明确不一致四级证据并组合计分，单字段未完全相等不得提前淘汰，独立来源共识只能有限加分。标题未知只作等待双语标题桥接的中间态，未经桥接不得入选或参与共识；候选先按综合证据排序，普通括号附注只作同分裁决。搜索使用标题主体并保留明确录音版本，新增候选不得反向清空已有合格候选；精确单条若独立证据不足，保留到并行目录池共同核验，模糊列表只作兜底；已排序候选逐条取正文，首条有效同步歌词立即停止。涉及语言版本的标准化只能遍历 ISO 语言集合，合作歌手括号不参与录音版本解析，禁止在首个播放请求扫描全部 Android 地区变体。验证：本地化名称、轻微拼写、双语标题、跨文字体系未知态、同源重复、错误标题、错误版本、合作歌手跨字段、括号附注分级、单来源、多发行候选、精确参数、短路加载和目标车机网络 smoke。边界：时长和明确录音版本仍为硬边界；不维护歌曲或人物特判表；UI 不解析第三方 JSON，也不得绕过领域选择器直接请求歌词源。
3. 触发条件：修改车机状态。动作：`IcarDisplayStateMonitor` 保持只读、事件驱动和失败保守；未知值不得猜测为可见或桌面态。验证：纯状态单测和目标车机 smoke。边界：不得接入 CAN 或未经验证的私有写接口。
4. 触发条件：修改缓存。动作：预算和淘汰阈值集中在 `LyricsCachePolicy`，缓存读取复用 `LyricsCandidateSelector` 的当前候选规则复核标题、歌手、专辑、录音版本和时长，不复制简化版身份判断。验证：策略单测；SQLite 行为变化补 Android 集成验证，并覆盖旧规则遗留错误项自动失效。边界：服务层只调用缓存接口，不复制缓存或候选规则。
5. 触发条件：需要跨两个以上调用点复用规则。动作：回到现有 owner 或新增边界清晰的抽象。验证：调用点不再存在重复实现。边界：不为单次文案或样式新增抽象。
6. 触发条件：系统窗口或跨应用桌面面板影响桌面/顶栏歌词。动作：`IcarDisplayStateMonitor` 事件驱动只读映射已验证的 `window_mode` 多值语义（`0/1` 清晰、`2/3` 占用、其它未知）；`SurfaceOccupancyLeaseService` 仅将版本化绑定租约转成进程内占用状态；`LyricsOverlayService` 通过 `IcarLyricsSurfacePolicy` 统一决定表面，租约优先于系统窗口值。占用只能使桌面歌词退回顶栏，歌词层可见性只能由安全几何决定。验证：窗口值、租约状态、未知值和有效几何单测，加协议服务可发现性与目标车机展开/收回 smoke。边界：不得写厂商设置、接私有窗口接口、轮询前台应用或按包名维护窗口清单；跨应用租约不得暴露业务 Binder 方法或直接操作歌词窗口。
7. 触发条件：准备在目标车机设置页暴露系统敏感授权入口。动作：先分别验证任务栈、触摸输入和权限能力；当前固件的通知使用权页面会对根视图启用遮挡触摸过滤，而常驻全屏 `SYSTEM_ERROR` 窗口会使触摸被系统丢弃，因此应用设置页不得暴露该无效入口。验证：源码或 APK 行为取证、窗口层级与真实触摸结果交叉确认，并检查设置页不存在授权控件和系统授权 Intent。边界：不使用隐藏 API、私有系统组件、自绘授权页、ADB 运行依赖或应用侧权限伪造；授权只作为外部受控部署前置条件。
8. 触发条件：`BroadcastReceiver`、升级恢复或其它后台入口通过 `startForegroundService()` 创建歌词服务。动作：服务 `onCreate()` 必须先创建通知渠道并立即履行 `startForeground()`，之后才能读取特殊授权、创建运行资源、停止或进入恢复态；缺权时释放运行资源、保留用户自动恢复意图并用可观察恢复状态结束，只有明确用户停止动作可以清除该意图。验证：双授权、分别缺失授权和主动停止的纯决策单测，加目标车机缺权启动 `10` 秒日志、通知、服务与监听绑定 smoke。边界：不得用延迟任务、轮询、自拉活、后台弹页或应用侧自行授权替代前台服务契约与系统授权。
