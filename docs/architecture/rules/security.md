# 安全规则

1. 触发条件：新增配置或环境信息。动作：可提交示例只保留占位符，真实路径、地址和凭证放被忽略的本机文件。验证：`git check-ignore` 和暂存前敏感信息扫描。边界：客户端必需的公开常量与机密分开判断。
2. 触发条件：新增 Android 权限。动作：同步 Manifest、产品价值、隐私说明和运行验证。验证：权限授予/拒绝路径 smoke。边界：与歌词主链无关的高风险权限不得加入。
3. 触发条件：处理外部服务数据。动作：只发送完成歌词匹配所需的歌曲元数据，不增加自建遥测。验证：请求构造和隐私文档核对。边界：不上传完整播放历史。
4. 触发条件：发布或重新授权。动作：先确认上游许可、来源说明和签名权利。验证：人工门禁。边界：技术上可推送不等于具备公开发布权利。
