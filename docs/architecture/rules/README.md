# 规则索引

## 1. 定位

1. 本目录只承接跨 `03lyrics` 多次任务复用的稳定规则。
2. 单次任务事实写进 `docs/progress.md`；产品和架构专有事实写进对应基线，不在规则库复制第二份。
3. 新任务按任务类型读取相关分类；发现重复判断时使用 `rule-discovery`。

## 2. 分类

| 分类 | 文件 | 内容 |
|---|---|---|
| 代码 | `code.md` | owner、依赖方向、错误处理、外部适配和复用抽象 |
| 设计 | `design.md` | 车机视觉、触控、歌词布局、状态和文案 |
| 产品 | `product.md` | 用户路径、范围、验收、非目标 |
| 验证 | `testing.md` | 单测、构建、实机 smoke、剩余人工确认 |
| 安全 | `security.md` | 权限、签名、密钥、日志和第三方数据 |
| 运维 | `operations.md` | 本机环境、ADB、构建、安装和发布门禁 |
| AI 协作 | `ai-collaboration.md` | 上下文读取、Skill、收尾和模板回流 |

## 3. 写入标准

每条规则必须写清触发条件、动作、验证方式和适用边界；可以机械执行时优先升级为脚本或测试。跨项目通用的内容必须去除 `03lyrics` 专有事实后再回流 `NewProject`。
