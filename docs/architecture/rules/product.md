# 产品规则

1. 触发条件：新增功能。动作：先确认它服务同步歌词核心路径，而不是 `03桌面` 的应用管理范围。验证：产品基线中有目标用户、完成现象和不做范围。边界：两个产品保持独立身份。
2. 触发条件：匹配结果不确定。动作：优先保持静默，不能为了“有歌词”展示错误歌曲或版本；候选时长差超过 `2` 秒、标题版本标记冲突或无法归为同一版本时都拒绝。验证：竞争版本、跨语言歌手展示、时长错版和歌手不一致测试。边界：可信同步歌词优先级高于覆盖率，不维护歌手别名表。
3. 触发条件：产品目标或承诺变化。动作：同步产品、架构、验证、隐私和进度文档。验证：文档快检和源码事实核对。边界：未来想法不得写成已实现事实。
4. 触发条件：涉及车辆安全能力、权限、公开发布或签名身份。动作：先取得人工确认并给出验证/回滚边界。验证：明确门禁记录。边界：不合理推断授权。
