# 03lyrics 项目长期总纲

## 1. 项目定位

1. `03lyrics` 是面向 iCAR 03 车机的轻量悬浮歌词应用。
2. 核心结果：从播放器公开的 Android MediaSession 获取播放信息，匹配同步歌词，并根据原厂桌面状态在顶栏或壁纸区域安全显示。
3. 正式运行不依赖 root、ADB、手机、电脑、自建后端或无障碍服务。
4. 本项目基于 `tcrrry/desktop-lyrics` 的历史继续适配；上游只作为来源追溯，当前默认远端为项目自己的 GitHub 仓库。

## 2. 平台基线

1. 目标车机：Android 9（系统 SDK 28）、`1920 x 1080`、型号标识 `S56_HQX`、高通 8155。
2. 工程基线：Kotlin Android，JDK 17，Gradle 8.2，Android Gradle Plugin 8.2.2，`compileSdk/targetSdk 34`，`minSdk 26`。
3. 当前应用身份：`applicationId/namespace = com.tcrrry.desktoplyrics`，`versionName = 1.14-icar03`，`versionCode = 114`。
4. 车机整体负载偏高，新增能力必须保持事件驱动、固定尺寸资源缓存和低绘制成本。

## 3. 物理主链

| 层级 | Owner | 职责与边界 |
|---|---|---|
| 设置入口 | `MainActivity.kt` | 在单一 Activity 内切换“显示 / 系统”，读取用户设置与服务启动所需的系统真实授权并向服务发送明确动作；现有车机主题色监听尚未通过实机验收，不作为已完成产品能力；不展示授权入口，不拥有播放或窗口状态机 |
| 设置控件 | `IcarSwitch.kt` | 用项目自有 `Checkable` 控件复现原车 `MBSwitch` 已验证的物理几何与开关无障碍语义；不依赖车厂私有类 |
| 系统授权入口 | `MediaListenerService.kt` | 提供 NotificationListenerService 绑定入口；不读取普通通知正文 |
| 应用流程 | `LyricsOverlayService.kt` | 前台服务契约、授权启动判定、恢复通知、MediaSession、播放时间线、窗口生命周期、表面切换、WebView 桥接 |
| 车机状态适配器 | `IcarDisplayStateMonitor.kt` | 只读观察已验证的 Global/Secure Settings 和存储事件；输出启动器、多值窗口占用与顶栏图标的纯显示状态 |
| 跨应用表面租约 | `SurfaceOccupancyLeaseService.kt` | 以版本化 exported bound Service 接收其它桌面区域的占用租约；绑定存续即占用，只发出进程内状态变化，不直接操作歌词窗口 |
| 外部数据适配器 | `DirectLyricsRepository.kt` | 并发查询 LRCLIB、QQ 音乐、网易云并限制网络响应 |
| 领域选择规则 | `LyricsCandidateSelector` | 用标题版本、专辑、时长和必要时的直接歌手名核验候选录音；未知或竞争结果保持静默 |
| 本地基础设施 | `LyricsCache.kt` | SQLite 歌词缓存、使用频率与批量淘汰 |
| 开机恢复 | `BootReceiver.kt` | 仅在用户已启用自动恢复时启动前台服务，并传递开机或应用升级来源 |
| 界面呈现 | `lyrics_overlay.html` | 顶栏/桌面歌词布局、逐行同步和 WebView 交互；主题由服务明确下发，不自行读取厂商状态 |
| 自动验证 | `app/src/test/` | 候选匹配、车机布局状态和缓存策略的 JVM 测试 |

## 4. 运行状态流

1. 任何由 `startForegroundService()` 创建的 `LyricsOverlayService` 都先创建通知渠道并立即调用 `startForeground()`；授权判断、运行资源创建、恢复退化、停止和异常处理全部发生在前台契约之后。
2. 服务集中读取启动来源、悬浮权限和通知使用权，并通过唯一启动策略进入 `RUNNING / RECOVERY / USER_STOPPED`；日志只记录这四类判定字段和最终状态，不记录媒体内容或用户数据。
3. 两项授权有效时清除旧恢复通知并沿唯一服务实例启动 MediaSession、车机监听和唯一 WebView/窗口。任一授权缺失时释放歌词运行资源、结束前台服务且返回 `START_NOT_STICKY`，保留 `PREF_AUTO_START`，并留下可点击进入现有 `MainActivity` 的常驻恢复通知；下一次授权有效的合法启动会清除该通知并重新进入同一运行主链。
4. 播放器变化经 MediaSession 回调进入服务；服务先查 `LyricsCache`，未命中或过期时调用 `DirectLyricsRepository`。
5. 外部来源并发返回候选，由 `LyricsCandidateSelector` 选择可信的同步歌词；无可信结果时不显示错误歌词。
6. `IcarDisplayStateMonitor` 把原厂启动器状态映射为 `DESKTOP` 或 `TOPBAR`，并事件驱动监听 `window_mode`：`0/1` 表示桌面歌词区域无系统窗口冲突，`2/3` 包含标准浮窗冲突；其它值或读取失败保守映射为 `TOPBAR`。
7. `SurfaceOccupancyLeaseService` 将外部桌面区域的绑定租约转成进程内状态；`LyricsOverlayService` 根据本应用设置页、租约、启动器状态、系统窗口占用和用户“壁纸歌词”设置计算唯一有效表面。租约和标准浮窗只使桌面歌词退回顶栏，不能隐藏有效几何内的歌词层。
8. 只有 `ACTION_STOP` 表示用户主动停止并清除自动恢复意图；授权失效只进入恢复态。开机或应用升级广播只有在该意图仍为真时才请求恢复服务。
9. Android 标准 `Configuration.uiMode` 是深浅主题唯一真值：设置页由 `values` / `values-night` 自动选色；常驻服务在配置变化时只向 WebView 下发 `light` / `dark`，不重载歌词页和播放时间线。
10. 设置页现有代码只读监听 `com.mb.provider.theme_key`，由 `IcarThemeColorPalette` 尝试映射原车色板；最新用户主测结论为主题色没有适配成功，因此该链路保持未完成状态，不改变深浅主题已经验收通过的结论，也不写车机设置或进入歌词服务、WebView 主链。
11. 设置页只在进入时通过 `NotificationManagerCompat.getEnabledListenerPackages()` 和 `Settings.canDrawOverlays()` 判断服务能否自动恢复；“系统”页不展示授权状态或跳转系统授权页。当前目标固件的敏感设置页会过滤被常驻覆盖窗口遮挡的触摸，授权属于应用外部的受控部署前置条件；`MainActivity` 保持普通 `singleTop` 启动模式。
12. `ACTION_RESTART` 只由 `LyricsOverlayService` 处理：同一服务实例先使旧运行代际失效，再注销 MediaSession、音频、AVRCP 与车机状态监听，移除并销毁唯一 WebView/窗口，重新读取显示偏好并重建运行资源；不经过 `ACTION_STOP`，不改变 `PREF_AUTO_START`。

## 5. 已验证几何不变量

所有坐标以 `1920 x 1080` 设计空间表达，运行时按真实屏幕等比换算。

1. 桌面歌词区域：`x = 660..1890`，`y = 90..900`。
2. 顶栏歌词基线：右边界 `x = 881`；没有动态图标时左边界 `x = 321`，可用宽度 `560 px`。
3. 已确认动态图标包括行人提醒、无线充电、SD 卡/DVR、USB 存储和守护模式。
4. 每个确认可见图标占用 `75 px`（`42 px` 图标 + `33 px` 安全间距）；未知状态不占用宽度。
5. 顶栏歌词最小可用宽度为 `180 px`；不足时隐藏该表面，不覆盖不确定区域。
6. 表面模式只由启动器状态、系统窗口占用、外部桌面表面租约和用户显示策略决定；图标可见性只影响顶栏几何，不改变表面模式。
7. 目标车机的 `Settings.Secure` 键 `com.mengbo.launcher3.settings.secure.window_mode` 的已确认多值语义为：`0` 无窗口、`1` 仅 ADAS 左侧卡片、`2` 标准浮窗、`3` 同时存在 ADAS 卡片和标准浮窗。仅 `0/1` 允许桌面歌词，`2/3` 退回顶栏；其它值或读取失败按未知占用保守处理。

## 6. 歌词匹配与网络不变量

1. 缓存未命中时并发启动 LRCLIB 精确单条、QQ 音乐目录和网易云目录请求；任一结果必须先通过本地录音核验且包含同步歌词，才能进入最终选择。
2. 正式歌词匹配只接受已知时长（至少 `1000 ms`），候选与当前播放时长差不得超过 `2000 ms`；现场、混音、重制、伴奏、翻唱、语言版等明确录音版本按类别核验，类别冲突或一侧明确标注而另一侧缺失时拒绝，同类版本的地点、年份等附加描述可继续比较。时长与明确录音版本是录音边界，不能被名称近似或来源数量抵消。
3. 标题、歌手和专辑统一形成 `EXACT / NEAR / UNKNOWN / DIFFERENT` 四级证据，不再因任一名称未完全相等就提前淘汰。统一分值为标题 `4 / 3 / 0 / -5`、歌手 `3 / 2 / 0 / -2`、专辑 `3 / 2 / 0 / -1`，标题必须先达到 `EXACT` 或 `NEAR` 且总分至少 `5` 才进入候选；两个独立来源描述同一录音时只加 `2` 分，同一来源重复结果不算共识。
4. 近似文本先做 Unicode、大小写、标点、空格和重音归一；标题、歌手、专辑的编辑相似阈值分别为 `85% / 90% / 80%`，且至少 `8` 个归一化字符才启用编辑距离。专辑核心文本覆盖达到 `70%` 可视为近似；明确双语括号标题可为跨文字标题提供等价桥接。跨文字体系且没有桥接时记为 `UNKNOWN`，只表示等待更多标题证据：不得单独入选、不得参与来源共识，也不能只凭歌手、专辑和时长补足。不维护人物、歌手或歌曲特判表。
5. `feat.`、`ft.`、`featuring`、`with` 属于合作歌手信息，不属于录音版本；允许该信息在标题括号与歌手栏之间移动，也允许来源省略已明确标注的合作歌手。普通标题括号附注不作硬门槛；候选先按综合分排序，同分时再按括号信息“完全一致、相似或省略、完全不一致”、独立来源数、时长差、来源和来源曲目 ID 排序。
6. LRCLIB 精确请求使用标题主体、有效歌手（含标题中的合作歌手）、有效专辑和毫秒时长换算值，只返回单条结果；精确结果单独达到阈值时立即返回，单独不足时保留到 QQ/网易云目录候选池共同核验。已排序候选逐条下载正文，第一条有效同步歌词立即返回；仅当前述路径全部失败时才请求 LRCLIB 模糊列表兜底，禁止先下载全部候选正文再等待最低优先级结果。
7. 精确与目录首轮最多等待 `1800 ms`，查询总截止 `3800 ms`；连接超时 `1500 ms`，读取超时 `2200 ms`，封面总截止 `3000 ms`，单响应最大 `2 MiB`。组合证据只复用现有目录结果，不增加请求；首轮最多 `17` 条目录候选，两两核验只在存在两个以上来源时执行。
8. 占位歌手、空内容、`null`、`[object Object]` 和普通无时间轴歌词不得进入顶栏同步歌词主链；WebView 不得绕过 `DirectLyricsRepository` 直接请求歌词源。选择日志最多记录前三条候选的分值、证据等级和独立来源数，不记录歌词正文。

## 7. 缓存不变量

1. 缓存上限 `128 MiB`，触发清理后目标为上限的 `90%`，每批最多淘汰 `256` 条。
2. 缓存使用 SHA-256 的标准化“歌曲 + 歌手 + 专辑 + 候选录音时长（秒级）”身份作为 key；读取时只探测当前播放时长正负 `2` 秒内的 key，并用当前候选规则重新核验标题、歌手、专辑、录音版本和实际时长，旧规则留下的不合格结果不得直接返回。
3. `30` 天后允许刷新歌词；访问频率最多累计 `30` 次，每次为淘汰分增加 `7` 天权重。
4. 缓存策略只由 `LyricsCachePolicy` 管理，服务层不得复制阈值。

## 8. 绝对边界

1. 不把 `03桌面` 的应用抽屉、安装、卸载、快捷控制或右侧手势面板放进本项目。
2. 不写车辆状态或厂商窗口状态，不连接 CAN，不调用未经独立验证的车厂私有控制接口。
3. 不使用 ADB、无障碍、轮询、持续截图或实时模糊支撑正式功能。
4. 不绕过 Android 原生权限、前台服务和悬浮窗机制。
5. 包名、签名和升级身份的变更必须先有独立迁移方案和实机升级验证。
6. 深浅主题适配不依赖厂商私有主题键、截图、亮度推断或轮询；仅设置页可只读监听已实机验证的公开主题色键作为强调色输入，且不得形成第二套深浅主题状态机、不得写回系统设置。
7. 标准浮窗互斥的启动编排属于实际发起应用启动的一方；本项目只在 `MainActivity` 清单元数据中声明标准浮窗身份。跨应用桌面区域冲突只接收版本化、无业务 Binder 的通用绑定租约，不识别调用方包名，也不接入其它产品源码。
8. 普通 APK 只能在已有通知使用权和悬浮窗授权后启动或恢复服务，不能写入系统通知监听列表、悬浮窗 AppOp，也不通过不可操作的系统敏感设置页伪装可用入口。若要求安装后零交互可用，必须另行走车厂平台签名、特权系统组件或受控部署授权；应用层不得伪造该结果。
9. 车厂私有 `MBSwitch` 仅作资源取证来源；正式 APK 使用项目自有控件承载同一几何、主题色和 Android 开关无障碍语义，不链接车厂私有类或资源 ID。
