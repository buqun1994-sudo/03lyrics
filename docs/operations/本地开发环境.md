# 本地开发环境

## 1. 逻辑依赖

1. JDK 17。
2. Android SDK，至少包含 Android 34 Platform、Build Tools 34.0.0、Platform Tools 和 Command-line Tools。
3. 仓库内 Gradle Wrapper。
4. Node.js，用于仓库文档、Skill 和环境快检脚本。

## 2. 本机配置入口

1. 将 `.codex/local-context.properties.example` 复制为 `.codex/local-context.properties`。
2. 本机文件至少配置 `JDK17_HOME`、`ANDROID_SDK_ROOT` 和 `PRIMARY_ADB`。
3. 需要实机时配置 `VEHICLE_ADB_SERIAL`；备用 ADB、共享工具链说明和 `NewProject` 模板源均为可选项。
4. `local.properties` 只配置 Android SDK，永不提交；可提交示例不得包含个人路径。

## 3. 检查入口

1. `node scripts/check-local-environment.mjs` 检查 JDK、SDK、Build Tools、Platform Tools 和 Gradle Wrapper。
2. `node scripts/check-local-environment.mjs --device` 额外检查当前 ADB 设备列表中是否存在目标车机。
3. `node scripts/install-and-smoke.mjs` 将当前 debug APK 保留数据覆盖安装到目标车机，启动设置页并检查版本、进程和致命日志。
4. 首选 ADB 不可用时，先停止继续操作并核对设备状态，再决定是否使用 `FALLBACK_ADB`；禁止同时运行相互冲突的 ADB Server。

## 4. 边界

1. JDK、Android SDK、ADB 二进制和 Gradle 缓存属于本机共享工具链，不复制进仓库。
2. ADB 只用于开发、安装、日志和实机验证，不进入正式运行主链。
3. 构建脚本不得读取提交文档中的个人绝对路径；统一由当前会话从本机上下文注入 JDK 环境。
4. 普通施工后的 debug APK 保留数据覆盖安装和应用范围最简日志检查属于默认收尾动作；清除数据、卸载、重启设备、安装 release 或抓取可能包含个人信息的广泛日志仍需用户当次明确指令。
