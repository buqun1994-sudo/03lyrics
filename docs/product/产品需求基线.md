# 03lyrics 产品需求基线

## 1. 产品定位

1. 产品名称与 Android 界面名称均为“03歌词”。
2. 目标用户：在 iCAR 03 原厂桌面、地图和其他车机应用中需要同步歌词的车主。
3. 核心问题：原厂界面没有稳定、克制且能适应顶栏动态图标的同步歌词显示。
4. 成功结果：播放歌曲时显示匹配正确、进度同步且不遮挡原厂关键区域的歌词；停止、切换界面和重启后状态符合用户意图。

## 2. 核心用户路径

1. 目标车机通过受控部署流程完成通知使用权和悬浮窗授权后打开应用；普通 APK 不能自行取得这两项系统授权。
2. 用户开启歌词服务并播放音乐。
3. 应用读取公开 MediaSession 数据，命中缓存或向公共歌词源查找同步歌词。
4. 地图、任意标准浮窗、已取得的桌面区域占用租约或未知车机状态显示顶栏歌词；原厂壁纸状态仅在桌面歌词区域未被占用且用户允许时显示桌面歌词。左侧 ADAS / 充电卡片不占用该区域，保持桌面歌词。
5. 用户可在同一设置窗口切换“显示”和“系统”：调整顶栏一行/两行、字号、壁纸歌词和默认开启的歌词翻译，并在歌词层异常时手动重启运行链路。
6. 两项授权均有效时，进入或返回设置页可自动恢复歌词服务；用户主动停止后不自动恢复，仍处于启用状态时车机重启或应用升级后恢复服务。
7. 自动恢复时若任一授权失效，应用不崩溃、不后台弹页，也不把“保持启用”改成主动关闭；歌词运行资源正常结束，并保留可点击进入现有设置页的恢复通知。授权重新有效后，下一次合法启动清除恢复状态并只恢复一套歌词运行资源。

## 3. 当前 V1 范围

1. MediaSession 歌曲信息、播放状态与进度同步；同一曲目已显示可信同步歌词后暂停时冻结当前行并保持显示，暂停时首次出现的新曲目仍等待真正播放。
2. LRCLIB、QQ 音乐、网易云多源同步歌词匹配；当前选中的 QQ 或网易云结果自身提供逐句翻译时，按用户设置随原文显示，不跨来源拼接或机器翻译。
3. 车机顶栏和桌面两种歌词表面及动态顶栏安全几何。
4. 本地歌词缓存、开机恢复和基础显示设置。
5. 无可信歌词时保持静默，不用低质量结果填充界面。
6. 设置页、顶栏歌词和桌面歌词跟随车机系统深浅主题，主题切换不打断当前歌词进度；车机系统主题色跟随当前未适配成功，不纳入已验收能力。
7. 原车设置、行车记录仪、账号、应用中心或同规格第三方页面打开时，桌面歌词自动退回顶栏且顶栏歌词持续可见；左侧 ADAS / 充电卡片展开时桌面歌词保持不动；会覆盖桌面歌词区域的自定义桌面面板通过通用占用租约退回顶栏，释放后按当前桌面状态恢复。
8. 设置页“系统”只提供“重启悬浮歌词”操作，不展示通知使用权或悬浮窗授权状态，也不打开目标固件上无法完成触摸操作的系统授权页面。
9. “重启悬浮歌词”是一次性恢复动作，使用右侧内容区全宽按钮且不保存为布尔设置；两项系统授权有效时执行，完成后保留显示偏好与自动恢复意图，并只留下一个前台服务、一个歌词悬浮窗和一套播放监听。
10. 开机或升级恢复缺少授权时显示常驻恢复通知，通知只打开现有 `MainActivity`，不后台弹页、不直接打开系统授权页，也不自行授权。

## 3.1 发行边界

1. 面向普通用户分发的 APK 不具备零点击开启通知使用权和悬浮窗权限的能力；把同一 APK 发给另一台车机不会携带开发机或其他设备上的授权状态。当前目标车机的外部受控调试授权只属于部署流程，不是正式运行依赖。
2. 若产品要求“安装后无需用户操作即可可用”，发行物必须由车厂作为平台签名或特权系统组件预装，并在系统配置中授予悬浮窗 AppOp 和通知监听访问权；这不是普通 APK 安装流程可以替代的能力。

## 4. 明确不做

1. 不建设歌词服务器、账号系统、应用商店或在线推荐。
2. 不提供 `03桌面` 的应用列表、拖拽排序、APK 安装、卸载或快捷控制。
3. 不控制空调、车窗、车锁、座椅、驾驶辅助或其他车辆安全功能。
4. 不要求 root，不常驻 ADB，不依赖手机或电脑。
5. 不读取麦克风、录制系统音频或读取普通通知正文。

## 5. 验收口径

1. 同一歌曲在可信同步歌词已存在时，顶栏和桌面表面按播放进度显示正确行。
2. 地图、任意标准浮窗、已取得的桌面区域占用租约和未知状态不会进入桌面大区域；左侧 ADAS / 充电卡片单独展开不触发回退；壁纸状态仅在桌面歌词区域未被占用且用户开启对应设置时进入桌面表面。
3. 五个已知动态图标全部出现时，顶栏仍保留至少 `180 px` 可用宽度；未知图标状态不触发猜测位移。
4. 歌名、歌手、专辑存在本地化、双语、发行后缀或轻微拼写差异时，候选可凭多项近似证据与独立歌词源相互印证进入匹配；任一名称未完全一致不再单独导致无歌词。歌名只有在已确认一致、近似或由双语标题证明等价后才可入选；无法确认的歌名不能只凭歌手、专辑、时长或来源数量展示。时长相差超过 `2` 秒、明确录音版本冲突、占位歌手、无同步时间轴或综合证据不足的候选仍保持静默。
5. 用户停止后重启车机不恢复；用户保持开启时重启或升级可恢复。
6. 在目标车机上，歌词层不得遮挡倒车影像、车辆安全警告或其他系统高优先级界面。
7. 系统在深色与浅色之间切换后，设置页与当前歌词表面使用对应配色；常驻歌词不因切换清空、跳行或重新匹配。
8. 当前不把车机系统主题色跟随列为验收通过项；现有主题键映射属于未完成实现，后续重新施工时必须单独完成实机验收。
9. 标准浮窗出现期间，歌词层只能在顶栏安全几何无效时隐藏；不得因本应用设置页或其它窗口打开而整体消失。
10. 设置页不展示或修改系统授权；进入页面时只读取两项系统真值决定能否自动恢复，运行过程中不轮询权限，也不依赖 ADB、Root、无障碍或车厂私有接口。
11. 手动重启后播放状态与歌词可继续更新，不产生重复悬浮窗、重复监听或致命日志，且不得等价为“主动停止”而清除自动恢复意图。
12. 由前台服务启动的自动恢复在任一授权缺失时，至少观察 `10` 秒不得出现 `RemoteServiceException`，通知监听服务保持系统绑定，`PREF_AUTO_START` 保持不变，并存在可点击的恢复通知。
13. 恢复两项授权后，设置页显式启动正常，恢复通知消失，歌词服务重新进入运行态且不存在重复服务、重复窗口或重复监听。
14. 同一曲目已有可信同步歌词且暂停前可见时，暂停后歌词保持在冻结位置；切换曲目、停止、会话消失或未命中可信歌词时立即隐藏，不能把旧歌词带到新内容。
15. 歌词翻译默认开启；同源翻译按时间戳与原句配对，缺失、无时间轴或无法配对的行只显示原文。桌面将原文与翻译作为一个歌词项滚动和高亮；顶栏一行显示当前原文与当前翻译，顶栏两行显示当前原文、当前翻译和下一句原文，关闭翻译后恢复原有一行/两行布局。
